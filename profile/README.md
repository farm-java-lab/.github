# Software Lecture Labs

Yazılım geliştirme konulu derslerde öğrencilerin proje bazlı olarak bir arada çalışabilecekleri örneklere yer verilmesi planlanan organizasyondur. Java, C# gibi nesne yönelimli dillerle kurumsal proje geliştirme deneyimini yaşamak ya da yapay zeka araçlarını kullanarak projeler geliştirmek için değerlendirilmesi planlanmaktadır.

## Amaçlar

Öğrencilerin;

- github gibi ortamlarda bir arada çalışmalarını sağlamak,
- pull-request, feature-based branch stratejisi, code review vb takım odaklı süreçleri deneyimletmek,
- derslerde işlenen kod örneklerini takip etmelerini kolaylaştırmak,
- iş arayışlarında belli kontrollerden geçmiş projeleri referans olarak verebilmelerini sağlamak
